## Project entry

**Scam & Fraud Analytics Dashboard | Power BI**

- Built a multi-page Power BI dashboard to explore 10,000 recorded cases across 12 apps, with headline metrics for total amount lost (approximately ₹8.68bn) and average loss per case (approximately ₹867.89K), as shown in the report.
- Created interactive report views for scam-type losses, app-level case and loss comparisons, year/quarter trends, age-group and platform analysis, state-level loss patterns, complaint sources, and recovery outcomes.
- Added slicers for reporting year/quarter, app category/name, user state, age group, gender, platform type, complaint source, outcome status, and ban status to support filtered investigation.
- Presented detailed app and case tables alongside trend, bar, donut, and map visuals to help users explore how reported cases and losses vary across dimensions.

**Important:** The source dataset provenance and full model logic are not documented in the screenshots alone. Verify the KPI definitions and any DAX / Power Query techniques in the PBIX before listing those as skills.

## Interview talking points

**What business problem does it explore?**  
It presents a structured way to inspect reported scam cases and financial-loss amounts across scam types, apps, demographics, states, complaint channels, and recovery outcomes.

**What does the dashboard let a user do?**  
Filter the report by time period and selected categorical dimensions, compare app- and state-level results, and inspect detailed case records.

**What limitations should you acknowledge?**  
The dashboard screenshots do not establish source-data provenance or prove causation. Financial figures should be interpreted using the measure definitions and data-quality checks available in the PBIX model.
